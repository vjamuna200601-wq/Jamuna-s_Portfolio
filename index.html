SheSafe – Women Safety System

Features: User registration and login, dashboard, source and destination entry, sample route-risk calculation, safer-route recommendation, sample risk score, sample traffic information, sample crime-level information, nearby police station details, nearby hospital details, prototype SOS feature, sample live-location link, Google Maps integration placeholder, logout option.

The current route-risk values are generated using sample data and Python's random module. This project is a prototype and does not currently contain a trained machine-learning model.

The current SOS feature returns a sample success response through the Flask /sos route. It does not currently send real SMS messages, WhatsApp messages, GPS alerts, or police notifications.

The current project includes a sample live-location feature, but continuous GPS tracking is not implemented in the current version.

OpenCV is not used in the current SheSafe implementation.
